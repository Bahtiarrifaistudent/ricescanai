Tentang Aplikasi

Teknologi CNN untuk Diagnosa Tanaman Padi

Menggunakan model Deep Learning berbasis Convolutional Neural Network (CNN) dengan arsitektur InceptionV3 untuk mengidentifikasi penyakit pada daun padi secara otomatis dari foto digital — akurat, cepat, dan mudah diakses.

  • Blast (Blas)
    Penyakit jamur Magnaporthe oryzae yang menyerang daun, leher, dan malai padi.
  • Blight (Hawar Daun)
    Disebabkan bakteri Xanthomonas oryzae yang menyebabkan daun menguning dan mati.
  • Tungro
    Penyakit virus yang ditularkan wereng hijau, menyebabkan pertumbuhan terhambat.

Tech Stack

Teknologi yang Digunakan

Dibangun dengan teknologi AI dan web terkini untuk performa optimal.

TensorFlow

Framework deep learning open-source untuk membangun dan melatih model neural network.

InceptionV3

Arsitektur CNN canggih dari Google, optimal untuk klasifikasi gambar presisi tinggi.

Flask

Web framework Python ringan sebagai backend API untuk menerima dan memproses gambar.

Python

Bahasa pemrograman utama untuk pengembangan model ML dan logika backend aplikasi.
